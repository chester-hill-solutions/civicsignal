# CivicSignal workspace mockup

Approved November 23, 2026.

[Open the interactive workspace mockup](civicsignal-workspace.html) in a browser. The approved treatment uses warm white surfaces, graphite controls, muted brick links, and signal red on the wordmark and Royal Assent marker.

The preview includes the review queue, Bill S-5 timeline, source search and inspection, briefings, and the brand guide in English and French. It uses a fixed set of public records. Briefing drafts and review status last for the preview session.
